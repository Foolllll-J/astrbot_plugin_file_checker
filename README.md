## 📖 简介

一款为 [AstrBot](https://astrbot.app) 设计的、功能强大的文件检查与预览插件。它可以精准检查文件是否有效，并能立即提供内容预览（支持文本、EPUB、压缩包、PDF等），在一段时间后对有效文件进行二次复核，以确保文件的可用性。

---

## ✨ 功能

* **🛡️ 全生命周期失效管理**
  采用"即时预检 + 延时复核"双重机制。支持**自动补档**功能，将失效文件加密打包为 ZIP 重新发送，确保文件可用性。
* **👁️ 内容预览**
  * **文档**: 支持 **PDF** (预览图)、**EPUB** (文本提取) 及 **30+种代码/文本** (编码识别)。
  * **压缩包**: 支持 ZIP/7Z/TAR 等多种格式解压预览，可预览文件结构或内部文本内容。
* **🎬 媒体转换**
  自动检测并转换视频 (MP4) 和图片 (JPG/PNG/GIF/WEBP) 为媒体消息发送，无需下载即可查看，并自动清理源文件。
* **🏷️ 文件名净化**
  支持自定义正则规则自动重命名群文件，去除冗余前缀/后缀。
* **♻️ 重复文件检测**
  自动识别群内历史文件，避免重复上传，并支持选择查重后的处理策略。
* **📦 备份转发**
  支持将文件自动转发到目标会话，可配置备份后缀名过滤和仅备份失效文件模式。

## 🚀 安装

1. **进入容器安装依赖**：如果你的 AstrBot 运行在 Docker 容器中，请先进入容器内部。
   
   ```bash
   docker ps  # 找到你的 AstrBot 容器ID
   docker exec -it <容器ID> bash  # 或者 sh
   ```
   
   然后在容器内安装 `zip` 依赖库：
   
   ```bash
   # 对于 Debian/Ubuntu 系统
   apt-get update && apt-get install zip p7zip-full
   # 对于 Alpine Linux 系统
   apk add zip p7zip
   ```
2. 下载本仓库。
3. 将整个 `astrbot_plugin_file_checker` 文件夹放入 `astrbot` 的 `plugins` 目录中。
4. 重启 AstrBot。

## ⚙️ 配置

首次加载后，请在 AstrBot 后台 -> 插件 页面找到本插件进行设置。插件支持多群配置模板，可为不同群聊设置不同规则。

### 配置模块说明

| 模块 | 说明 |
|------|------|
| **文件检查** | 有效性检查、查重策略、文件名净化规则 |
| **文件预览** | 文本/压缩包/PDF 预览、媒体文件转换 |
| **文件补档** | 失效后自动补档，可配置补档后缀和密码 |
| **文件备份** | 转发文件到目标会话，可配置备份后缀和仅备份失效文件 |

> [!TIP]
> 备份转发的目标会话需是 AstrBot 支持发送主动消息的平台。

## 💡 使用

本插件采用两阶段文件检查模式，并为每个群长期维护一份文件索引缓存，上传文件时自动增量刷新，仅缓存未命中或文件发生变更时才发起 API 调用。

#### 文件名净化

配置文件名净化规则后，文件上传后立即按正则规则重命名群文件，不中断后续检查流程。

#### 重复文件检测

根据查重策略决定行为：
- 仅通知：不操作，只提示重复
- 自动清理旧文件：删除群文件中的旧副本
- 延迟删除新文件：10 分钟后删除新上传的文件

#### 即时预览与诊断

文件上传后，在预检延时后执行首次检查：
- 文件有效 → 发送成功通知（文本/EPUB/压缩包内容预览或PDF预览图），文件进入延时复核队列
- 文件失效 → 发送警告，根据配置自动补档

#### 自动补档

文件失效时自动打包为加密 ZIP 重新上传。可配置补档后缀范围和 ZIP 密码。

#### 文件备份转发

配置备份转发后，文件处理完成后自动转发到目标会话。支持按后缀名过滤和仅备份失效文件模式。

#### 媒体转换

视频文件在阈值内自动转为 MP4 消息发送；图片在启用自动转换后转为 JPG/PNG/GIF/WEBP 媒体消息。

#### 延时复核

复核延时结束后对队列中的文件二次检查：
- 文件仍有效 → 保持沉默
- 文件已失效 → 引用回复原消息，发送失效通知

#### Bot 文件处理

插件同样支持处理机器人自身发送的文件，遵循相同的净化、查重和检查流程。

> [!TIP]
> 建议配合 [QQ 群文件管家](https://github.com/Foolllll-J/astrbot_plugin_GroupFS) 使用，效果更佳。
